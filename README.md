# legacy_support

Plugin de compatibilidad legacy para [FSFramework](https://github.com/eltictacdicta/fs-framework).

Repositorio: https://github.com/eltictacdicta/legacy_support

## Qué incluye

- Traducción y carga de plantillas RainTPL legacy (`.html`)
- Compatibilidad con plugins y vistas de FacturaScripts 2017
- Validación de versiones de plugins legacy
- Instrumentación del uso de componentes legacy en el panel de administración
- Soporte de hashes de contraseña legacy (SHA1/MD5) con migración automática al login

## Dependencias

Ninguna. Recomendado para instalaciones que usen plugins heredados de FacturaScripts 2017.

## Instalación

```bash
git clone https://github.com/eltictacdicta/legacy_support.git plugins/legacy_support
```

O desde el panel: **Admin → Tienda de Plugins → Descargar**.
